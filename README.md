# :thinking: Game Idea
A roguelike dungeon crawler where the player explores a dungeon made up of randomly generated rooms, each populated with a randomly generated set of enemies. The final room in the dungeon is always a boss room.

After clearing each room, the player is rewarded with a choice of one buff out of three options. Defeating the boss unlocks a new playable character - four characters in total.
